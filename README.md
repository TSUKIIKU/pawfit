# PawFit 喵练

个人定制化每日健身饮食规划单页应用。纯前端、离线可用，所有数据仅保存在浏览器 `localStorage`。

## 直接使用

双击打开 [index.html](index.html) 即可。无需安装依赖、无需启动服务器，也不依赖任何外部 API、字体或第三方库。

首次进入会通过 3 步引导采集身体数据、运动基础、健身目标与运动场景，然后自动生成：

- BMI、BMR（Mifflin-St Jeor）、TDEE、每日目标热量
- 蛋白质 / 碳水 / 脂肪目标克数与占比
- 4 周阶段训练计划与每日三餐推荐食谱

## 主要功能

- 训练：5 种目标、居家 / 健身房 / 混合场景、52 个动作、3 套 4 周模板、逐周递进与每 4 周自动进阶。
- 自适应：根据前一天完成度、训练时长、RPE 与近期负重，自动调整当天训练容量。
- 打卡：支持常规力量动作、计时支撑动作和有氧动作，记录组数、次数 / 秒数、负重、时长与感受。
- 饮食：200 条内置食物、模糊搜索、克 / 份换算、自定义食物、三餐推荐、六类记录与营养统计。
- 图表：原生 Canvas 绘制营养素饼图与体重 / 体脂趋势折线图。
- 追踪：体重、体脂率、胸围、腰围、臀围、臂围、腿围。
- 激励：9 枚猫咪勋章、解锁动画、训练提醒与饮水提醒。
- 数据：支持导出 / 导入 JSON 备份，也可在应用内清空全部本地数据。

## 数据与隐私

- localStorage 键：`pawfit.state.v1`
- 不发起网络请求，不上传个人数据。
- 所有猫咪、勋章和动作插画均为 HTML 内联 SVG。
- 清理浏览器站点数据会删除记录，建议定期在「我的 -> 数据管理」导出备份。
- 营养与训练建议仅供一般健康管理参考，不替代医生、营养师或专业教练的诊断与处方。

## 静态部署

只需部署 `index.html` 一个文件：

- GitHub Pages：将仓库推送到 GitHub，在 Settings -> Pages 选择分支和根目录。
- Netlify：将 `index.html` 拖入 Netlify Drop，或连接仓库后设置发布目录为根目录。
- Vercel：导入仓库，Framework Preset 选择 Other，直接使用静态文件部署。

部署后可把网址添加到手机主屏幕，获得接近原生应用的入口体验。

## 兼容性

- 移动端优先，适配 320px 及以上宽度。
- 手机使用底部 Tab，桌面使用顶部导航；桌面内容最大宽度 1200px。
- 需要支持 Canvas、localStorage 与现代 CSS Grid 的浏览器。

## 食物种子数据

`data/seed/cfct/` 为《中国食物成分表标准版（第 6 版）》JSON 数据集，应用内食物数据独立内嵌在 `index.html` 中。种子数据仍在仓库中保留，供后续扩展使用。

- 字段说明、单位、缺失值约定与许可证：`data/seed/cfct/README.md`
- 单文件导入入口：`data/seed/cfct/foods.json`（1677 条）
- 升糖指数表：`data/seed/cfct/gi.json`（259 条）
- 版本与校验和：`data/seed/cfct/manifest.json`

重新拉取：

```sh
node scripts/fetch-cfct-seed.mjs              # 跟随 main
node scripts/fetch-cfct-seed.mjs --ref <sha>  # 锁定提交
```

需要 Node 18+（使用内置 `fetch`），无需安装依赖。
